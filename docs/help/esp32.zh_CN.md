ESP32 触控盒是一块刷了触控盒固件的 ESP32 开发板：手机把它当成接上的触摸屏、键盘、鼠标和手柄，不开 USB 调试也能操作。这个扩展负责找到开发板、把它们列在“设备”页、刷写固件，并经串口（或 Wi-Fi）把触控发给开发板。

## 选板子

- **ESP32-S3、ESP32-S2、ESP32-P4**：用 USB 线插手机，手机把它当成硬件触摸屏。P4 走高速 USB，延迟最低；P4 没有 Wi-Fi，只能用串口连电脑。
- **经典 ESP32、ESP32-C3、ESP32-C6**：没有 USB 设备功能，经蓝牙连手机。第一次在手机的蓝牙设置里配对“GameScrcpy XXXX”，以后开机自动回连，延迟比 USB 多几毫秒。
- 板子至少要有 4 MB 闪存，常见开发板都满足。

## 接线 {两根线}

1. **接手机**：S3、S2 用板上标着“USB”的原生口，P4 用“USB 2.0 OTG HS”口，经 OTG 线插手机。蓝牙的板子这一步改成在手机上配对。
2. **接电脑**：用板上的另一个口（USB 转串口，常标着“UART”或“COM”）接电脑。C3、C6、P4 也可以用芯片自带的 USB 串口口。Windows 自带这些串口的驱动。
3. **在程序里找到它**：扩展打开后会依次试乐鑫、CH34x、CP210x 的串口，找到的开发板作为触控盒出现在“设备”页。点卡片上的“控制”可以不看画面直接操作手机；也可以在某台手机的设置里把触控方式选成 ESP32，投屏时就经开发板触控。

> [!TIP]
> 只有一个原生 USB 口的 S2 小板，要在 GPIO43（TX）/ GPIO44（RX）上外接一个 USB 转串口模块接电脑。

## 设置在哪里

- **“设备”页开发板卡片**：“设置”打开这块开发板自己的窗口：它是什么、固件、试一下、Wi-Fi、名字和诊断。“更多”里有试一下、刷写固件、诊断和断开。
- **“扩展”页这个扩展的卡片**：“设置”列出找到的所有开发板，可以向任意串口刷写固件，包括还没有应答的板子。
- **某台手机的设置**：触控方式 ESP32，以及这个扩展针对这台手机的设置：串口（auto 或 COM7 这样的串口）、连接方式（串口或 Wi-Fi）和 Wi-Fi 地址。对所有手机生效的值在扩展的设置里。

## 刷写与升级固件

在开发板卡片的“更多”里选“刷写固件”，或者在扩展的设置里选开发板接在电脑上的串口，再点“刷写固件”。扩展自带固件和刷写工具，一般会自己让板子进入下载模式，大约半分钟写完，写完校验无误后板子自动重启。新版本的扩展带了更新的固件时，开发板的窗口里会提示有新版本可以升级。

- **什么时候按 BOOT**：提示“没有进入下载模式”时，按住板上的 BOOT 键（有的板子标 IO0），同时插上数据线（或按一下 RST / EN），然后松开 BOOT，再点一次刷写。
- **旧固件**：板子上还是旧的 QineTouch 固件时，卡片上会写“旧固件”。旧固件只能触摸，键盘、鼠标、手柄和 Wi-Fi 要新固件。

## 用 Wi-Fi 连接

板子接在串口上时，从卡片打开它的窗口，在“Wi-Fi”一组填网络名和密码，点“保存 Wi-Fi”；扩展同时给这块板子生成一个只有这台电脑知道的密钥。之后在扩展的设置（或某台手机的设置）里把连接方式改成 Wi-Fi，地址留空就会自动找到板子，也可以填它的 IP 地址。Wi-Fi 比串口多 1～3 毫秒延迟，偶尔会抖动。

## 这些提示是什么意思

- **“这个口上没有应答”**：板子一个字节都没回。两个 USB 口的 S3、S2 上，电脑要接标着“COM”或“UART”的那个口（USB 转串口芯片），标着“USB”的口接手机；再检查一下线。
- **“开发板一直在重启（复位原因 …）”**：板子一遍遍打印开机信息、就是不回话。再刷一次固件；一直这样就检查板子是不是至少 4 MB 闪存、供电够不够。
- **“开发板处在下载模式”**：它在等刷写工具。按一下板上的 RST（EN），再重新查找开发板。
- **“这个口上收到的数据不像 ESP32 触控盒”**：有东西在回话，但不是这个协议：口不对、波特率对不上，或者板子在能说话之前就重启了。
- **“开发板上是旧版 QineTouch 固件”**：刷上新固件之前只能触摸。
- **“正在被 … 使用”**：别的扩展或你自己的逻辑占着这个串口；它放开后，或者你重新查找开发板时，开发板会回来。
- 卡片上的“诊断”会询问开发板是什么，并说明哪里不对；结果显示在开发板的窗口里。

## 安全与小提示

- 电脑 2 秒没有发来任何东西时，板子会抬起所有手指、松开所有按键与鼠标键、手柄回中，手指不会卡在手机上。
- 点“试一下”会在手机屏幕正中点一下，用来确认手机那头接好了。
- 手机正在经这块开发板控制时，开发板卡片会写“正在被投屏窗口使用”，要等那个窗口关掉才能刷写。
- 手机接了 ESP32 的键盘后，Android 默认不再弹出屏幕上的输入法；需要时在手机的“物理键盘”设置里打开“显示虚拟键盘”。
